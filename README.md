1. 전체 UI 디자인 개선

기존의 다소 칙칙하고 무거운 색상 구성을 전체적으로 수정
배경 및 주요 UI 요소를 화이트 & 골드 계열로 변경
전체적으로 밝고 깔끔한 느낌을 주도록 디자인 개선
버튼, 입력 영역, 카드 및 주요 컴포넌트의 색상과 스타일을 통일
기존 기능은 유지하면서 모던하고 고급스러운 분위기가 나도록 UI 개선

2. 가격 수정 기능 오류 수정

기존 가격 수정 과정에서 백의자리 등의 특정 숫자를 수정하면 가격 값이 0으로 변경되는 오류 발생
숫자 일부를 수정할 때 기존 가격 데이터가 정상적으로 유지되지 않는 문제 확인
가격 입력 및 수정 로직을 수정하여 숫자의 일부를 변경해도 전체 가격 값이 정상적으로 유지되도록 개선
가격 수정 후에도 정확한 금액이 저장 및 표시되도록 수정

3. 가격 추가/감소 조작 기능 추가

가격을 빠르게 조정할 수 있도록 마우스 클릭 방식의 가격 조절 기능 추가
마우스 왼쪽 클릭: 가격 증가
마우스 오른쪽 클릭: 가격 감소
반복적으로 숫자를 직접 입력하지 않아도 원하는 가격을 빠르게 조정할 수 있도록 개선
가격 변경 시 현재 가격을 기준으로 정상적으로 증감되도록 처리
우클릭 시 기본 브라우저 컨텍스트 메뉴가 나타나는 것을 방지하여 가격 감소 기능으로 정상 동작하도록 처리

4. 사용성 개선

가격을 직접 입력하여 세밀하게 수정하는 방식과 마우스를 이용해 빠르게 증감하는 방식을 함께 사용할 수 있도록 개선
기존 기능의 동작을 최대한 유지하면서 사용자가 가격을 보다 직관적으로 조작할 수 있도록 변경
UI 디자인과 가격 조작 방식을 함께 개선하여 전체적인 사용 편의성과 시각적 완성도 향상
